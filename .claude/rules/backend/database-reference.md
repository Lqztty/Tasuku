# データベースリファレンス

## 参照の重要性

`src/app/` または `src/database/` 配下のファイルを**閲覧・編集・プラン作成**する際は、作業開始前に必ずデータベース構造を確認すること。

## データベース構造の確認方法

### 1. マイグレーションファイルの確認

マイグレーションファイルは時系列順に命名されており、テーブル構造の変遷を追うことができる。

```bash
# マイグレーションファイルの場所
src/database/migrations/
```

### 2. Model の確認

Eloquent Model は `src/app/Models/` に配置されている。

Model を確認することで：
- リレーション（`hasMany`, `belongsTo` 等）
- アクセサ・ミューテータ
- キャスト設定
- スコープ

を把握できる。

## 主要テーブル一覧

テーブルを追加したら、機能のまとまりごとに下の形式で追記する。

| テーブル名 | 説明 | 主要カラム |
| ---------- | ---- | ---------- |
| `users` | ユーザー | `id`, `name`, `email` |
